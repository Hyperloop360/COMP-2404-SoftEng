PURPOSE:

This is a C++ progrma that acts as a Bank. You can manage bank customers, accounts and transactions both credit and debit.
The user can view hte bank custmers as well as their accounts, create new transactions, process pending transactions upto the
current date and view the history of transactions.

LIST OF SOURCE FILES:

- main.cc
- Bank.cc
- Customer.cc
- Account.cc
- Transaction.cc
- Date.cc

LIST OF HEADER FILES:

- Bank.h
- Customer.h
- Account.h
- Transaction.h
- Date.h
- defs.h

COMPILATION AND LAUNCHING INSTRUCTIONS:

1. Open a terminal in the directory containing all program source and header files.
2. Compile the program by running the provided Makefile command:
   make
3. Launch the compiled executable:
   ./bank
4. Clean up object files and executables when finished:
   make clean
